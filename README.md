# Gas Leakage Detection System (MERN Stack)

A web-based system designed to monitor gas levels and trigger alerts when values exceed safe thresholds.

## Features

- Real-time data monitoring (simulated)
- Threshold-based alert system
- Dashboard for data visualization
- Continuous data updates
- Scalable backend design

## Tech Stack

Frontend: React.js, HTML, CSS  
Backend: Node.js, Express.js  
Database: MongoDB  

## Project Structure

client/ → React frontend  
server/ → Backend APIs  

## Setup

1. Clone the repository
git clone https://github.com/your-username/gas-detection.git

2. Install dependencies
cd server && npm install  
cd ../client && npm install  

3. Configure environment variables
MONGO_URI=your_mongodb_uri  

4. Run the application
cd server && npm start  
cd client && npm start
